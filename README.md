# 🎓 Student Result Analyzer

## 📌 About Project
This project analyzes student results using NumPy and Pandas.
It calculates grades, rankings, and subject-wise statistics.

## 🛠️ Tools Used
- Python
- NumPy
- Pandas

## ✨ Features
- Missing values handling
- Grade system (A+, A, B, C, D, F)
- Pass / Fail result
- Student ranking
- Subject wise statistics
- Top 3 students
- Export to CSV and Excel

## 📊 Grade System
| Marks    | Grade |
|----------|-------|
| 90 - 100 | A+    |
| 80 - 89  | A     |
| 70 - 79  | B     |
| 60 - 69  | C     |
| 50 - 59  | D     |
| Below 50 | F     |
